# Support

WorkOps is a young, community-supported open-source project. There is no paid support, no staffed help desk, and no response-time guarantee.

## Where to get help

| Need | Channel |
| --- | --- |
| Setup, configuration, deployment | [Getting started](docs/getting-started.md) · [Configuration](docs/configuration.md) · [deployment guides](docs/deployment/vercel.md) |
| "How do I…?" questions | [User guide](docs/user-guide.md) · [FAQ](docs/faq.md) |
| Something is broken | [GitHub Issues](https://github.com/wa1939/WorkOps/issues) using the bug report template |
| Feature ideas | [GitHub Issues](https://github.com/wa1939/WorkOps/issues) using the feature request template |
| Security vulnerabilities | **Not here** — follow [SECURITY.md](SECURITY.md) |

## Before opening an issue

1. Search existing issues — your problem may already be reported.
2. Confirm you are running a recent state of the default branch.
3. Collect the basics: deployment type (Docker / Vercel / bare server / local dev), commit, database, browser, relevant log output, and steps to reproduce.

## What to expect

Issues are triaged and fixed on a best-effort basis by the maintainer and contributors. There is no SLA. If you need a fix urgently, PRs are welcome — see [CONTRIBUTING.md](CONTRIBUTING.md).

## Commercial support

None is offered at this time.
